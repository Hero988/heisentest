# heisentest

**Open huge log files in your browser. Nothing is uploaded.**

Drop a log file — hundreds of megabytes, gigabytes — onto [heisentest.com](https://heisentest.com)
and analyze it instantly: filter as you type, see the whole file as a timeline, click the error
spike, correlate multiple files. Everything runs locally in your browser tab. Your logs never
leave your machine — try it with wifi off.

Work in progress. This README will grow with the tool.

## Develop

```
npm install
npm run dev     # local dev server
npm run check   # typecheck + tests + build
```
